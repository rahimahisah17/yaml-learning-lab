# SKILL.SCH YAML Learning Lab

A hands-on YAML learning lab focused on understanding YAML syntax, data structures, data types, multiline strings, anchors, aliases, validation, and practical DevOps configuration.

This repository contains practical exercises completed while learning how YAML is used to represent structured configuration data in cloud and DevOps environments.

## What I Practiced

- YAML key-value pairs and mappings
- Nested structures
- Sequences and lists of objects
- YAML data types
- Comments and quoted strings
- Multiline strings using `|` and `>`
- Anchors, aliases, and merge keys
- Multi-document YAML streams
- GitHub Actions workflow syntax
- YAML validation with Python and PyYAML
- Git and GitHub workflow

## Validation

The YAML files were validated using Python and PyYAML.

The validation process also included checking for illegal tab characters, helping ensure the files follow YAML indentation and syntax requirements.
